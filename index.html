Binary MIDI Music Lab — 5 Octaves

MIDI note numbers → real-world pitch values → shown as 7-bit binary

This version uses standard MIDI note numbers for pitch. Each MIDI value is shown in decimal and as a 7-bit binary number. Black tiles are pitches that can be named as either a sharp or a flat. For example, C♯ and D♭ share the same MIDI pitch value.

Each octave contains 12 distinct pitches: C, C♯/D♭, D, D♯/E♭, E, F, F♯/G♭, G, G♯/A♭, A, A♯/B♭, B.

Encoding Table

This table uses MIDI note numbers 36–95 (C2 through B6). MIDI note numbers use the range 0–127, which fits in 7 bits. Enharmonic spellings such as C♯ and D♭ share one MIDI number because they represent the same pitch in equal temperament.
